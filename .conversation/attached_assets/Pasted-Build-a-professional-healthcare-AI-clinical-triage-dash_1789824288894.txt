Build a professional healthcare AI clinical triage dashboard called "PulseAI".

PulseAI is an AI-assisted clinical triage and clinical report analysis workspace designed for healthcare professionals. It is decision-support software and must clearly indicate that AI outputs require clinician review.

Create a modern, professional clinical interface with a dark slate background and subtle glassmorphism.

Use this visual palette:
- Background: #0B0F17
- Primary teal: #0D9488
- Secondary blue: #2563EB
- Alert/coral red: #EF4444
- White/light gray text

Create a persistent left sidebar containing:

1. PulseAI logo/name at the top
2. Triage Queue
3. Patient Records
4. Lab Report Analyzer
5. AI Referral Drafter
6. Settings

At the top of the main content area create:
- Global search
- "Triage Agent: Active" status indicator
- Clinician profile/avatar area

The main dashboard should contain a page title:
"Clinical Triage Dashboard"

Add a small subtitle:
"AI-assisted clinical decision support — clinician review required."

Create four metric cards:
- Patients in Queue
- High Risk / Critical
- Average Triage Time
- Reports Processed

Create a prominent laboratory report upload area with:
- Drag and drop support
- "Upload Lab Report" button
- PDF/document icon
- Text saying "Upload a patient laboratory report for AI-assisted triage analysis"
- A secondary option to select an existing patient

Below the upload area create a "Triage Queue" table.

The table should have these columns:
- Patient Name
- Age / Sex
- Chief Complaint
- Risk Level
- Key Flagged Biomarker
- Wait Time
- Action
